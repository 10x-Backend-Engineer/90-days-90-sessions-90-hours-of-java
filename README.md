# **90 days. 90 sessions. 90 hours of deliberate practice.**

**One language. Multiple disciplines. One hour every morning.**

Voici le curriculum complet, avec une seule contrainte de programmation : **Java sera ton unique langage de code pendant ces 90 jours.**

On ne va pas transformer cette roadmap en formation Spring Boot. Le but est de développer une culture informatique générale : programmation, algorithmique, systèmes, réseaux, sécurité, infrastructure et ingénierie logicielle.

## **2. Daily protocol**

**04:45 – 05:45**

Daily commitment

# **60 minutes**

| Duration | Activity                  |
| -------- | ------------------------- |
| 5 min    | Recall yesterday's lesson |
| 15 min   | Study the day's resource  |
| 30 min   | Hands-on practice         |
| 10 min   | Test, document and commit |

**Every session must produce an artifact.**

Examples: Java source code, solved DSA problem, Linux lab notes, CTF write-up, architecture diagram or CI/CD configuration.

**Rules:**

- One daily objective, no multitasking.
- Maximum 15 minutes of passive learning.
- Minimum 30 minutes of active practice.
- Use Java for all programming exercises.
- Bash commands and configuration files are permitted when studying Linux and infrastructure.
- If a task is not finished in 60 minutes, document the remaining work and continue another day when necessary.

# **5. The rules of your Engineering Arc**

1. **One language:** Java for all programming exercises and projects.
2. **One hour:** protect your 04:45–05:45 session.
3. **One objective:** follow the assigned mission, not whatever tutorial catches your attention.
4. **Practice first:** build something before watching another tutorial.
5. **Document everything:** your GitHub repository is evidence of your progress.
6. **Never miss twice:** if you miss a morning, resume at the next available opportunity.
7. **Don't rush:** understanding is more important than completing a checklist.


At the end, you won't have mastered every domain. But you will have 90 hours of structured practice, tangible deliverables and a much clearer idea of which engineering disciplines you want to pursue further.

*One Hour of Coding. Every morning. No hype. Just code and progress.*
